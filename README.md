# Biserry-Grocery
Quality everyday groceries and food stuffs 

## AI Catalogue Manager upgrade
The admin Bulk Upload page now supports richer supplier/master CSV data, supplier header aliases, SKU/barcode/fuzzy matching, category markup calculations, price-change safeguards, image reuse from matched catalogue items, confidence scoring, duplicate-resistant matching, and an exception/approval queue.

See `AI-CATALOGUE-MANAGER.md` for operating rules and `functions/` for the Firebase Cloud Functions automation scaffold. The bundled 1,200-row starter catalogue is in `data/biserry-1200-master-catalogue.csv`.
