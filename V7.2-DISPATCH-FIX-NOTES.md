# Biserry v7.2 — Guest Dispatch Request Fix

## What this fixes

- Guest checkout customers can request an available dispatcher without creating a Biserry account.
- Signed-in customers continue to work.
- A dispatch request document uses the order ID as its document ID, limiting each order to one live dispatch request.
- Declined/cancelled requests can be offered to another available dispatcher.
- Public order tracking allows exact order-ID lookups but blocks collection listing.
- Raw Firestore permission errors are replaced with customer-friendly messages.
- The order confirmation page passes the order ID directly to the Dispatch page.
- Service-worker cache version is bumped so mobile/PWA users receive the corrected JavaScript.

## Required Firebase action

Replace the current Firestore rules with `firestore.rules.v72-dispatch-fix` and Publish.

The admin email expected by these rules is `admin@biserry.com`.

## Cost

This fix uses the existing Firebase Authentication/Firestore architecture and does not add Cloud Functions, Cloud Tasks, SMS, paid WhatsApp, or a paid AI API.
