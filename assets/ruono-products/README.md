# Ruono product thumbnails

These 107 WebP files are deterministic crops of the product artwork in the eight supplied Ruono price-list pages. They contain no generated or substituted imagery.

`data/ruono-product-images.json` maps each catalogue group to its stable asset path and records the source attachment plus crop box. Rebuild the assets with `scripts/build-ruono-product-images.py <source-directory>` when the original page files are available.
